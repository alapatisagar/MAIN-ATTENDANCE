How to Deploy Online Anywhere on Render.com

This project is 100% cloud-ready with zero external database dependencies. Deploy online for free in under 2 minutes!

  1. 1. Push to GitHub

    Push this codebase folder to your GitHub repository.

  2. 2. Log into Render.com

    Sign up/Login at Render.com and click New + → Web Service.

  3. 3. Connect Repository

    Select your GitHub repository. Render will automatically detect render.yaml or auto-fill configurations:

    • Runtime: Node
    • Build Command: npm install
    • Start Command: npm start
  4. 4. Click "Create Web Service"

    Render will build and deploy your live HTTPS link (e.g. https://employee-attendance-app.onrender.com) accessible from any mobile phone or laptop!
